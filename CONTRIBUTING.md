# Contributing Guidelines

Thank you for your interest in this infrastructure and DevOps portfolio! While this repository primarily showcases personal homelab configurations and automation scripts, constructive feedback, bug reports, and ideas are always welcome.

## How to Contribute

1. **Reporting Issues:** If you spot a bug in a script or have a suggestion for improvement, please open an [Issue](../../issues) with a clear description and context.
2. **Pull Requests:** 
   - Fork the repository and create a new branch for your changes (`git checkout -b feature/your-idea`).
   - Keep code clean, modular, and well-commented.
   - Ensure no sensitive data (IP addresses, keys, tokens) are included before submitting.
   - Open a Pull Request describing what your changes do and why.

## Code Standards

- **Python:** Follow PEP 8 style guidelines where applicable.
- **Ansible / YAML:** Maintain clean 2-space indentation and idempotent task structures.
