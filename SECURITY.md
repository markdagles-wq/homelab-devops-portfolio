# Security Policy

## Supported Versions

This repository represents an active homelab infrastructure and DevOps portfolio. Security patches and hardening updates are applied continuously to the main branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, misconfiguration, or exposed sensitive data within this repository, please report it privately instead of opening a public issue.

- **Contact:** rewol@post.cz
- **Response Time:** I aim to acknowledge security reports within 48 hours and address verified issues promptly.
